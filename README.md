PROJETO SQL 🎲


Projeto desenvolvido em SQL para análise de dados de vendas, utilizando consultas, JOINs, CTEs e Window Functions para identificar indicadores de faturamento, desempenho de produtos e comportamento dos clientes.


Onde aplico meus conhecimentos em SQL, desde comandos básicos para consulta e manipulação de dados, como
SELECT, WHERE, ORDER BY, GROUP BY, HAVING, INSERT, UPDATE e DELETE, até recursos avançados, como JOINs, subconsultas, CTEs (Common Table Expressions) e Window Functions.
Experiência prática na criação de consultas, organização, análise e transformação de dados, buscando desenvolver soluções eficientes para extração de informações e geração de insights.
